SQL Interview Cheat Sheet — Core 9 Patterns

All standard, CTE, window function, and Snowflake QUALIFY solutions transcribed for direct interview recall.

01 · Duplicates Multiple Approaches

Find Duplicate Rows (NAME, DEPT) — All Ways

Single column: use NAME only. Full-row duplicates: list every column. Pattern: COUNT(*) > 1.

A: GROUP BY + HAVING
SELECT NAME, DEPT, COUNT(*) AS total
FROM EMPLOYEES
GROUP BY NAME, DEPT
HAVING COUNT(*) > 1;
B: Subquery IN (returns full row details)
SELECT * FROM EMPLOYEES
WHERE (NAME, DEPT) IN (
    SELECT NAME, DEPT FROM EMPLOYEES
    GROUP BY NAME, DEPT
    HAVING COUNT(*) > 1
);
C: ROW_NUMBER() in CTE (entire copies)
WITH dups AS (
    SELECT *, ROW_NUMBER() OVER (
        PARTITION BY NAME, DEPT 
        ORDER BY EMP_ID
    ) AS rn
    FROM EMPLOYEES
)
SELECT * FROM dups WHERE rn > 1;
D: COUNT() Window Function
SELECT * FROM (
    SELECT *, COUNT(*) OVER (
        PARTITION BY NAME, DEPT
    ) AS total
    FROM EMPLOYEES
) WHERE total > 1;
02 · Deduplication Keep Latest

Delete Duplicates — Keep Latest Record

ORDER BY ... DESC keeps newest; ASC keeps oldest. rn = 1 is always the surviving record.

A: DELETE + USING + ROW_NUMBER() (Snowflake / PG)
DELETE FROM EMPLOYEES
USING (
    SELECT EMP_ID, ROW_NUMBER() OVER (
        PARTITION BY NAME, DEPT 
        ORDER BY CREATED_AT DESC
    ) AS rn
    FROM EMPLOYEES
) AS d
WHERE EMPLOYEES.EMP_ID = d.EMP_ID AND d.rn > 1;
B: CTE DELETE (SQL Server)
WITH d AS (
    SELECT *, ROW_NUMBER() OVER (
        PARTITION BY NAME, DEPT 
        ORDER BY CREATED_AT DESC
    ) AS rn
    FROM EMPLOYEES
)
DELETE FROM d WHERE rn > 1;
C: NOT IN + MAX (latest = highest ID)
DELETE FROM EMPLOYEES
WHERE EMP_ID NOT IN (
    SELECT MAX(EMP_ID)
    FROM EMPLOYEES
    GROUP BY NAME, DEPT
);
D: Table Rebuild with QUALIFY (Snowflake native)
CREATE OR REPLACE TABLE EMPLOYEES AS
SELECT * FROM EMPLOYEES
QUALIFY ROW_NUMBER() OVER (
    PARTITION BY NAME, DEPT 
    ORDER BY CREATED_AT DESC
) = 1;
03 · Nth Salary Tie-Proof

3rd Highest Salary — All Ways

Nth highest: rnk = N, OFFSET N-1, or subquery count N-1. DISTINCT is mandatory with LIMIT + OFFSET.

A: DENSE_RANK() in CTE
WITH r AS (
    SELECT SALARY,
           DENSE_RANK() OVER (ORDER BY SALARY DESC) AS rnk
    FROM EMPLOYEES
)
SELECT DISTINCT SALARY FROM r WHERE rnk = 3;
B: QUALIFY (Snowflake 1-Pass)
SELECT DISTINCT SALARY FROM EMPLOYEES
QUALIFY DENSE_RANK() OVER (ORDER BY SALARY DESC) = 3;
C: Nested MAX (3rd salary specific)
SELECT MAX(SALARY) FROM EMPLOYEES
WHERE SALARY < (
    SELECT MAX(SALARY) FROM EMPLOYEES
    WHERE SALARY < (SELECT MAX(SALARY) FROM EMPLOYEES)
);
D: LIMIT + OFFSET
SELECT DISTINCT SALARY 
FROM EMPLOYEES
ORDER BY SALARY DESC
LIMIT 1 OFFSET 2;
E: Correlated Subquery
SELECT DISTINCT SALARY 
FROM EMPLOYEES e1
WHERE 2 = (
    SELECT COUNT(DISTINCT SALARY)
    FROM EMPLOYEES e2
    WHERE e2.SALARY > e1.SALARY
);
04 · Partitioned Nth Per Department

Nth Highest Salary per Department (N = 3)

Highest per dept: rnk = 1 (or GROUP BY DEPT + MAX). Ties return multiple rows because DENSE_RANK leaves no gaps.

A: DENSE_RANK() + PARTITION BY
WITH r AS (
    SELECT NAME, DEPT, SALARY,
           DENSE_RANK() OVER (
               PARTITION BY DEPT 
               ORDER BY SALARY DESC
           ) AS rnk
    FROM EMPLOYEES
)
SELECT * FROM r WHERE rnk = 3;
B: Snowflake QUALIFY
SELECT NAME, DEPT, SALARY 
FROM EMPLOYEES
QUALIFY DENSE_RANK() OVER (
    PARTITION BY DEPT 
    ORDER BY SALARY DESC
) = 3;
C: Correlated Subquery
SELECT NAME, DEPT, SALARY 
FROM EMPLOYEES e1
WHERE 2 = (
    SELECT COUNT(DISTINCT SALARY)
    FROM EMPLOYEES e2
    WHERE e2.DEPT = e1.DEPT 
      AND e2.SALARY > e1.SALARY
);
05 & 06 · Averages Tie-Safe

Department Averages & Highest Average Dept

AVG() ignores NULLs. LIMIT 1 drops tied departments—use B or C if ties must be preserved.

05 · Grouped vs Window Average
-- A: Aggregated (one row per department)
SELECT DEPT, ROUND(AVG(SALARY), 2) AS avg_salary
FROM EMPLOYEES
GROUP BY DEPT;

-- B: Preserving every employee row
SELECT NAME, DEPT, SALARY,
       AVG(SALARY) OVER (PARTITION BY DEPT) AS dept_avg
FROM EMPLOYEES;
06 · Highest Average Dept (Tie-Safe)
-- Snowflake QUALIFY + DENSE_RANK (Tie-Safe)
SELECT DEPT, AVG(SALARY) AS avg_salary
FROM EMPLOYEES
GROUP BY DEPT
QUALIFY DENSE_RANK() OVER (ORDER BY AVG(SALARY) DESC) = 1;

-- Standard SQL (Tie-Safe via HAVING)
SELECT DEPT, AVG(SALARY) AS avg_salary
FROM EMPLOYEES
GROUP BY DEPT
HAVING AVG(SALARY) = (
    SELECT MAX(avg_sal) FROM (
        SELECT AVG(SALARY) AS avg_sal
        FROM EMPLOYEES GROUP BY DEPT
    ) t
);
07 · Outliers Department Comparison

Employees Earning More Than Their Department Average

Window functions cannot go directly into a WHERE clause—use a CTE or Snowflake QUALIFY.

A: Correlated Subquery
SELECT NAME, DEPT, SALARY 
FROM EMPLOYEES e1
WHERE SALARY > (
    SELECT AVG(SALARY)
    FROM EMPLOYEES e2
    WHERE e2.DEPT = e1.DEPT
);
B: JOIN to Aggregated CTE
SELECT e.NAME, e.DEPT, e.SALARY, d.dept_avg
FROM EMPLOYEES e
JOIN (
    SELECT DEPT, AVG(SALARY) AS dept_avg
    FROM EMPLOYEES
    GROUP BY DEPT
) d ON e.DEPT = d.DEPT
WHERE e.SALARY > d.dept_avg;
C: CTE with Window Function
WITH a AS (
    SELECT *, AVG(SALARY) OVER (
        PARTITION BY DEPT
    ) AS dept_avg
    FROM EMPLOYEES
)
SELECT NAME, DEPT, SALARY, dept_avg
FROM a
WHERE SALARY > dept_avg;
D: Snowflake QUALIFY
SELECT NAME, DEPT, SALARY 
FROM EMPLOYEES
QUALIFY SALARY > AVG(SALARY) OVER (PARTITION BY DEPT);
08 · Time Series ROWS vs RANGE

Running Total & Moving Average

2 PRECEDING AND CURRENT ROW calculates a 3-row moving average. Without ROWS, the default frame (RANGE) groups tied timestamps together.

A: Window Frames (Running Total & 3-Row Average)
SELECT ORDER_DATE, AMOUNT,
       SUM(AMOUNT) OVER (
           ORDER BY ORDER_DATE
           ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
       ) AS running_total,
       AVG(AMOUNT) OVER (
           ORDER BY ORDER_DATE
           ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
       ) AS moving_avg_3
FROM ORDERS;
B: Reset Per Customer (Partitioned)
SELECT CUSTOMER, ORDER_DATE, AMOUNT,
       SUM(AMOUNT) OVER (
           PARTITION BY CUSTOMER
           ORDER BY ORDER_DATE
           ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
       ) AS running_total
FROM ORDERS;
C: Correlated Subquery (No Window Functions)
SELECT o1.ORDER_DATE, o1.AMOUNT,
       (SELECT SUM(o2.AMOUNT) 
        FROM ORDERS o2 
        WHERE o2.ORDER_DATE <= o1.ORDER_DATE) AS running_total
FROM ORDERS o1;
09 · Anti-Joins NULL Traps

Customers Who Have Never Placed an Order

NOT IN evaluates to empty if the subquery returns even a single NULL. Always enforce IS NOT NULL or use NOT EXISTS.

A: LEFT JOIN + IS NULL
SELECT c.*
FROM CUSTOMERS c
LEFT JOIN ORDERS o ON c.CUSTOMER_ID = o.CUSTOMER_ID
WHERE o.CUSTOMER_ID IS NULL;
B: NOT EXISTS (Recommended)
SELECT *
FROM CUSTOMERS c
WHERE NOT EXISTS (
    SELECT 1 FROM ORDERS o 
    WHERE o.CUSTOMER_ID = c.CUSTOMER_ID
);
C: NOT IN (Must filter NULLs)
SELECT *
FROM CUSTOMERS
WHERE CUSTOMER_ID NOT IN (
    SELECT CUSTOMER_ID FROM ORDERS 
    WHERE CUSTOMER_ID IS NOT NULL
);
D: EXCEPT (MINUS in Oracle)
SELECT CUSTOMER_ID FROM CUSTOMERS
EXCEPT
SELECT CUSTOMER_ID FROM ORDERS;
